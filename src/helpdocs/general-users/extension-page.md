# Reading an extension page and downloading

An extension page brings together everything the developer has told us about the extension,
what other users think of it, and whether there is any security warning about it.

## At the top

- **Security warning** (only if there is one). If the Vulnerable Extensions List has published
  an advisory about this extension you see a banner:
  - *Security advisory* - an **unpatched** vulnerability is published for this extension. Read
    the advisory before installing or continuing to use it.
  - *Security notice* - a vulnerability in **earlier versions** has been fixed; make sure you run
    the fixed version (shown as "fixed in *version*").
  - **Read the advisory** opens the full advisory. See
    [Checking the Vulnerable Extensions List](vulnerable-extensions-list.md).
- **Name** and, when you are signed in, the **favourite** button.
- **By** *developer* - links to the developer's profile.
- The **star rating** and number of reviews.
- Where the extension sits in the category tree.

## The description

Below the logo you find the developer's introduction and description. Developers can add:

- a **video** - it only loads when you click it. A note tells you where it is hosted; playing a
  YouTube or Vimeo video sends your IP address and browser details to that service;
- **screenshots** (up to 8);
- **tags**.

## Downloading

The **Download** button takes you to the developer's own download. Note that:

- the download is **hosted by the developer, not by the JED**;
- some extensions ask you to **register or sign in** at the developer's site first - the page
  tells you when that is the case;
- paid extensions are bought from the developer.

Other buttons link to the developer's **Website**, **Demo**, **Documentation**, **Support**,
**Licence**, **Changelog** and **Source code**, where the developer provided them. They all open
in a new tab.

> For help **using** an extension, always contact the developer (the *Support* button). The JED
> team does not provide support for extensions.

## The facts panel

| Fact | Meaning |
|---|---|
| **Version** | The latest version the listing shows. For many extensions this is updated automatically from the developer's update server. |
| **Last updated** | When the listing last changed. |
| **Date added** | When the listing was first published. |
| **Includes** | Component, Module, Plugin, Language, Extension Specific Addon... |
| **Compatibility** | The Joomla versions the developer states. "using B/C plugin" means Joomla's backward-compatibility plugin must be enabled. |
| **Licence** | The licence name the developer gives. |
| **Tags** | Click a tag to see other extensions with it. |

## Scores

The **Overall score** and the five scores below it - **Functionality**, **Ease of Use**,
**Support**, **Documentation** and **Value for Money** - are averages of the **published
reviews**. "Not Rated" means there is nothing to average yet.

Use **Write a review** to add your own (or **Edit my review** if you already wrote one) - see
[Writing reviews](writing-reviews.md).

## Reviews

Published reviews are shown in an accordion, newest first. Each heading shows the version
reviewed, the review title, the reviewer's overall stars and the date. Open a review to read:

- the general comments;
- each score with the reviewer's comment on it ("Not rated" where they skipped a score);
- **I use this for** - what the reviewer uses the extension for;
- the **Developer response**, if the developer answered and the JED team published the answer.

## Related extensions

- **Add-on for** - this extension extends another product (for example "Add-on for
  VirtueMart").
- **Add-ons for this extension** - other listings that extend this one (only add-ons the JED
  team has confirmed appear here).
- **Also available as** - the free or paid version of the same extension, listed separately.
- **More by** *developer* - other extensions from the same developer.

## Reporting the listing

Use **Report this extension** if something about the **listing** is wrong - for example it
breaks the JED rules, a link is broken, or you believe it copies someone else's work. This opens
a support ticket for the JED team. You need to be signed in. See
[Reporting and tickets](reporting-and-tickets.md).

Use the VEL instead for **security problems** - see
[Reporting a vulnerability](reporting-a-vulnerability.md) - and the abandoned form for an
extension that **seems no longer maintained** - see [Abandoned extensions](abandoned-extensions.md).

## Blocked listings

Sometimes the JED team takes a listing offline while a problem is resolved. Instead of the
listing you then see **"This listing is currently unavailable"** with:

- the **reason** (for example *Listed on the Vulnerable Extension List*, *Licensing violation*,
  *Invalid download link*) and its code;
- where available, **Read more about this reason**, linking to the Knowledgebase article;
- **Browse other extensions**.

The listing returns once the reason has been resolved.

A listing that has been deleted answers "This extension has been deleted". A listing that is not
(or no longer) published simply cannot be found.
