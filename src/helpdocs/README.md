# JED Help Documentation

Help for everyone who uses the Joomla! Extensions Directory (JED), the Vulnerable Extensions
List (VEL) and the Abandoned Extensions list. The documentation is split by who you are:

| You are... | Start here |
|---|---|
| Looking for an extension, reviewing one you use, reporting a problem, or checking whether an extension is vulnerable or abandoned | [General users](general-users/README.md) |
| A developer who lists (or wants to list) extensions on the JED | [Extension developers](developers/README.md) |
| A member of the JED team, the VEL team, or a site administrator running the JED | [JED team](jed-team/README.md) |

## What is on the site

The JED site is made up of three parts that work together:

- **The Extensions Directory** (component `com_jed`): the catalogue of extensions, with
  reviews, developer profiles, favourites, the developer dashboard and the support ticket system.
- **The Vulnerable Extensions List** (component `com_vel`): published security advisories about
  third-party Joomla extensions, the public report and fix-notice forms, feeds and an API.
- **Abandoned Extensions** (component `com_abandonware`): the public list of extensions the JED
  team has concluded are no longer maintained, and the form for reporting one.

## Related material

The JED **Knowledgebase** (installed by the *JED Knowledgebase* sample data) holds the policy
documents these guides refer to: the Terms of Service, *Submission Requirements Made Easy*,
*Extension Names*, *The GPL & the JED*, *Joomla! Update System Requirement*, *Submitting a
Review*, *Submission Error Codes* and *Unpublished Extensions Error Codes*, among others.
These help documents explain **how to use the site**; the Knowledgebase explains **the rules**.
