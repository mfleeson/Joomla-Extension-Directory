# Language keys used in the administrator

Every `COM_JED_*`, `COM_VEL_*` and `COM_ABANDONWARE_*` key the administrator can show, and where it is
defined. Generated by `php tests/language/check-language-keys.php --side=admin --list=...`; see that
script for which files count as administrator code.

| Status | Meaning |
|---|---|
| admin | Defined in the admin language files (`com_x.ini` or `com_x.sys.ini`) |
| copied from site | Was only defined in the site file, so it showed as a raw key; copied by this script's `--fix` |
| undefined | Defined in no language file |
